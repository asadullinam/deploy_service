# [Done] TASK-026: Массовое удаление проектов через отдельную страницу

## Контекст

Сейчас удалить можно только один проект за раз из карточки проекта.
Нужен сценарий выбора нескольких проектов и их пакетного удаления.

## Что сделать

### 1. Отдельная страница массовых операций

- Добавить отдельную страницу/раздел UI со списком проектов для bulk-операций.
- Для каждого проекта добавить чекбокс выбора.
- Добавить действие «Выбрать все / Снять выбор».

### 2. Массовое удаление

- Добавить кнопку «Удалить выбранные».
- Перед удалением показывать подтверждение с количеством выбранных проектов.
- Удаление можно выполнять последовательно через текущий endpoint `DELETE /projects/{id}`.
- После завершения показывать итог:
  - сколько удалено успешно,
  - по каким проектам была ошибка.

### 3. UX/безопасность

- Кнопка удаления неактивна, если ничего не выбрано.
- Для удалённых проектов обновлять список без ручного рефреша.
- Ошибки по отдельным проектам не должны прерывать удаление остальных.

## Файлы (ориентировочно)

## Мини-отчет

- Добавлен отдельный экран `Массовое удаление` в сайдбаре и роут `#/bulk-delete`.
- На экране реализован список проектов с чекбоксами, действия `Выбрать все` и `Снять выбор`, счетчик выбранных и блокировка кнопки удаления при пустом выборе.
- Реализовано последовательное удаление выбранных проектов через `DELETE /projects/{id}` с подтверждением перед запуском.
- Ошибки по отдельным проектам не прерывают операцию: после завершения показывается итоговый отчет с количеством успешных удалений и списком ошибок.
- Списки проектов обновляются автоматически после bulk-операции без ручного рефреша.
