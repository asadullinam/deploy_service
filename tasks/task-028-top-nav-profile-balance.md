# [Done] TASK-028: Дашборд, биллинг и список проектов — улучшение навигации и UX

## Проблема

Текущий UI не полностью покрывает ожидаемый пользовательский flow:

- Из блока/вкладки биллинга на дашборде переход в полноценный экран биллинга и пополнение счета недостаточно очевидны.
- Форма создания проекта расположена слишком высоко и мешает быстрому просмотру списка проектов.
- Карточки статистики на дашборде (всего/активные/приостановленные) не используются как навигация в список проектов с фильтрами.
- На дашборде перегружен блок метрик: карточка «Доступно средств» должна быть убрана.

## Что сделать

### 1. Биллинг: переход и пополнение

- Обеспечить явный переход на страницу «Биллинг» из блока «Биллинг аккаунта» на дашборде.
- На странице «Биллинг» добавить/оставить кнопку пополнения счета как основной CTA.
- Проверить, что пополнение корректно обновляет отображаемые значения баланса в UI.

### 2. Перенос создания проекта вниз списка

- Перенести блок «Создать проект» в нижнюю часть сайдбара (ниже списка проектов).
- Список проектов должен открываться пользователю сразу, без прокрутки до него.

### 3. Кликабельные карточки статистики на дашборде

- Сделать кликабельными карточки:
  - «Всего проектов»;
  - «Активные»;
  - «Приостановленные».
- По клику открывать единый список проектов с примененным фильтром:
  - «Всего» — без фильтра;
  - «Активные» — фильтр `active`;
  - «Приостановленные» — фильтр `suspended`.
- Фильтр должен быть быстро снимаемым/переключаемым без перехода на отдельную страницу.

### 4. Упростить набор карточек на главном дашборде

- Удалить карточку «Доступно средств» из верхнего блока статистики.
- На главном дашборде должны остаться 3 карточки: всего/активные/приостановленные.
