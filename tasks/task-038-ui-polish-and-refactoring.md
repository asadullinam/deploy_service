# TASK-038: UI polish and refactoring [Done]

## Контекст

После серии функциональных задач накопился ряд визуальных и смысловых несоответствий: лишние описания, дублирующиеся тексты, неоднородные подписи, неочевидные иерархии. Задача — пройтись по всему UI и привести его к единообразному, лаконичному виду.

---

## Категории изменений

### 1. Глобальная навигация

**Текущее состояние:**

- Верхняя панель: «Дашборд» / «Проекты» / «Проект» / «Биллинг» + «Тёмная тема» + «Токен» + «Выйти»
- Пункт «Проект» в навигации видим, но означает «последний открытый проект» — неочевидно

**Изменения:**

- Убрать пункт «Токен» из навигации (решается в task-037)
- Переименовать «Проект» -> «Среда» (более точно отражает концепцию vcluster-среды)
- Сократить: «Тёмная тема» -> иконка без текста на мобильном, оставить как есть на десктопе

### 2. Dashboard

**Текущие проблемы:**

- Подзаголовок страницы слишком длинный: «Быстрый обзор проектов, баланса и текущего состояния платформы»
- Карточки «Всего проектов» / «Активные» / «Приостановленные» без каких-либо иконок или визуальных подсказок
- Секция «Выбранный проект» пустая если проект не выбран — некрасиво
- Кнопки быстрых действий «Создать проект» / «Перейти в биллинг» / «Пополнить на 1 000 $» расположены внизу, малозаметны

**Изменения:**

- Подзаголовок: «Обзор активности и баланса» (короче)
- В карточках стата добавить числовую динамику или убрать статику если 0/0 всегда
- Секция «Выбранный проект» если проект не выбран — скрыть полностью или показать «Выберите проект из раздела Проекты»
- Кнопку «Пополнить на 1 000 $» — заменить на поле с произвольной суммой (или вынести в биллинг)

**Текущие проблемы:**

- Кнопка «Режим редактирования» -> переименовать в «Выбрать» (понятнее)

### 4. Страница «Проект» (детали)

**4.1 Шапка проекта**

**Текущее:** Hero-блок с заголовком «Сводка среды», длинным описанием, ID в отдельной карточке, статусом и кнопками действий.

**Изменения:**

- Убрать подзаголовок «Среда собрана и готова к работе. Публичный адрес появится здесь после назначения.» — дублирует статус из пилюли
- Вместо отдельного блока ID — показывать ID рядом с именем проекта меньшим шрифтом
- Описание действия «Среда активна. Доступны пауза и удаление проекта.» — убрать, понятно из кнопок

**4.2 Вкладка «Обзор»**

**Текущее:** Две колонки — «Доступ» (URL, Grafana) и «Хронология» (Создан, Обновлён), ниже «Текущее состояние в кластере» и «Стоимость проекта».

**Изменения:**

- Раздел «Доступ» переименовать -> «Адреса» (точнее)
- Если публичный адрес не назначен — вместо «ещё не назначен» показывать «—»
- Раздел «Хронология» убрать (служебная информация, доступна через API, в UI занимает место)
- Кнопка «Обновить статус» -> «Получить статус» (первый вызов — получение, не обновление)

**4.3 Вкладка «Контуры»**

**Текущее:** Список контуров с кнопками редактирования/удаления, форма создания нового контура.

**Изменения:**

- Статус «failed» отображается как пилюля без поддержки повторной инициализации — добавить кнопку «Переинициализировать» (или хотя бы tooltip почему failed)
- Форма создания: placeholder «staging» -> «staging / preview / dev»
- Убрать повторяющийся заголовок в заглушке «Нет активных контуров. Создайте первый.» — оставить только если реально нет ни одного

**4.4 Вкладка «Деплой»**

**Текущее:** Большая форма с полем GitHub токена, URL репозитория, веткой, именем сервиса, Dockerfile, типом сервиса, портами, репликами, профилем ресурсов.

**Изменения:**

- Поле «GitHub token (опционально: разовый override для этой операции)» — сократить label -> «Временный токен (разовый)»
- Хинт «Основной токен лучше сохранить через кнопку «Токен» в верхнем меню...» — убрать (после task-037 токен переедет в вкладку «Деплой»)
- Label «Ссылка на репозиторий GitHub» -> «Репозиторий»
- Label «Основная ветка» -> «Ветка»
- Label «Путь к Dockerfile» -> «Dockerfile»
- Label «Тип доступа» -> «Тип сервиса»
- Label «Порт снаружи» -> «Внешний порт»
- Label «Порт приложения» -> «Порт контейнера»
- Label «Количество копий» -> «Реплики»
- Профили ресурсов: добавить краткое описание к каждому (Starter — 0.25 CPU / 256MB, Balanced — 0.5 CPU / 512MB, Performance — 1 CPU / 1GB)
- Кнопку «Автозаполнить» переименовать -> «Определить из репозитория»
- Кнопку «Создать PR» -> «Создать PR с деплой-конфигом»

**4.5 Вкладка «Состояние»**

**Текущее:** Список namespace, deployment, service, pods из кластера. Кнопка «Обновить статус».

**Изменения:**

- Заглушка «Пока нет данных» + описание -> оставить, но добавить пояснение что нужно нажать кнопку
- Если статус загружен — добавить timestamp последнего обновления («Обновлено: 23 мар. 2026 г., 12:08»)

**4.6 Вкладка «Релизы»**

**Текущее:** Список релизов с фильтром по контуру, кнопка «Обновить».

**Изменения:**

- Заголовок «История развертываний» -> «История релизов»
- Кикер «История деплоя» -> убрать (дублирует заголовок)
- В карточке релиза убрать «Контур: Production» если этот контур выбран в фильтре (избыточно)
- Добавить статусы цветовыми полосками или иконками (сейчас только текст в пилюле)

**4.7 Вкладка «Доступ»**

**Текущее:** kubeconfig download/rotate, публичный URL, Grafana.

**Изменения:**

- Кнопка «Скопировать в base64» -> «Скопировать kubeconfig»
- Блок «Публичный адрес» дублирует то что в «Обзоре» — оставить только здесь, убрать из Обзора (или наоборот)
- Заголовок «Настройки доступа» -> «Доступ к среде»
