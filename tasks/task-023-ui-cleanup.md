# [Done] TASK-023: UI cleanup — боковое меню, читаемость, удаление лишних элементов

## Проблема

Текущий UI содержит ряд usability-проблем, которые делают его непригодным для демонстрации.

## Что сделать

### 1. Убрать информационные надписи про JWT и API

На главном экране или в форме авторизации есть поясняющий текст про то, как работает JWT, как получить токен и т.д. Этот текст нужно удалить — он предназначался для разработчика, не для пользователя.

### 2. Убрать прямой доступ к API (Swagger / OpenAPI)

Убрать из UI ссылку или кнопку «API» / «Swagger» / «OpenAPI». Доступ к `/swagger` через браузер не трогать — убрать только элемент навигации в самом UI.

### 3. Боковое меню — сделать выпадающим

Сейчас левое меню видно всегда. Нужно:

- По умолчанию меню скрыто (collapsed).
- Есть кнопка-гамбургер или стрелка, которая разворачивает/сворачивает меню.
- При переходе на конкретный проект меню автоматически скрывается (collapsed).

### 5. Убрать пояснительный текст в разделе «Биллинг аккаунта»

В разделе биллинга отображаются служебные объяснения алгоритма работы платформы, предназначенные для разработчика:

- _«Перед созданием PR считаем доступный остаток как разницу между балансом и расходами за месяц, а затем сравниваем его с резервом под новый деплой.»_
- _«Если доступный остаток падает до нуля, активные проекты автоматически ставятся на паузу.»_
- _«Этому аккаунту разрешён обход денежного лимита.»_

Весь этот текст нужно убрать. Числовые показатели (баланс, расходы, доступно) оставить.

### 4. Белый/читаемый текст при выделении проекта в списке

При выборе проекта в списке фон строки становится синим, а текст остаётся серым или зелёным -> текст нечитаем.

Нужно: при активном/выбранном состоянии строки проекта текст должен быть белым (или другим контрастным цветом с достаточным контрастом WCAG AA ≥ 4.5:1).

Проверить все варианты состояний: hover, active/selected, visited.
