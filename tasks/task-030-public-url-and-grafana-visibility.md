# TASK-030: Разобраться, почему не отображаются публичный адрес и Grafana

## Проблема

В UI не отображаются публичный адрес проекта и ссылка/виджет Grafana, хотя ожидается их доступность после деплоя.

## Что сделать

### 1. Провести расследование по цепочке данных

- Проверить источник `publicUrl` и данных по Grafana на backend-стороне.
- Проверить, что значения корректно сохраняются в проекте/stage/release (в зависимости от текущей модели).
- Проверить API-ответы, которые использует UI для рендера этих полей.

### 2. Исправить backend или UI (по факту причины)

- Если проблема в backend: восстановить заполнение и отдачу полей.
- Если проблема в UI: исправить маппинг/рендер и обработку пустых состояний.
- Для отсутствующих данных выводить понятный статус, а не "пусто без причины".

### 3. Добавить проверку регрессий

- Тест/проверка на сценарий "после успешного деплоя публичный адрес и Grafana отображаются".
